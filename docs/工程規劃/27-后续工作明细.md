## C. 明确不做（勿排期）

- 游客结账  
- 以图搜图  
- 分期 / 定金预售  
- **余额充值**（余额仅来自佣金转入 + 售后退余额）  
- 固定「7 天无理由」文案  
- 快递公司轨迹第三方 API  
- **二级及以上分销**  
- 复杂运营画布 / A/B  
- 海报可视化设计器
