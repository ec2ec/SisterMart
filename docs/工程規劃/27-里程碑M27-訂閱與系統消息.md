## 目标

1. 首页订阅邮箱落库；**登录用户已有效订阅则隐藏订阅模块**。
2. 后台订阅名单：关闭 / 恢复 / 删除。
3. 系统消息：全局或指定用户、可勾选发邮件、富文本正文。

## 范围

- 表：`newsletter_subscribers` / `system_message_batches` / `mail_outbox`
- API：订阅、`newsletter/me`、后台名单；消息 `member_ids` + `send_email`
- H5：Home 订阅；消息详情支持 HTML
- Admin：訂閱名單页；消息页 RichEditor + 选人 + 邮件勾选
