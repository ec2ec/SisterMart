# 里程碑 M22 — 售後證據審核工作流

| 项 | 内容 |
| --- | --- |
| 状态 | **本地通过** |
| 前置 | M17 证据上传已关闭；M21 本地通过 |
| 支付 / WhatsApp | 继续暂缓 |
| 分支 | `cursor/m22-aftersale-evidence-review-fc0f` |

## 目标

补齐后台对售后证据的**查看 + 带备注审核**体验；退货退款通过时若无证据则拦截。

## 范围

1. Admin `AftersalesView`：详情抽屉（描述、大图证据、备注输入、通过/驳回/确认退货/强制余额）
2. `review`：`return_refund` 且无证据 → `EVIDENCE_REQUIRED`；驳回须填 `admin_note`
3. 列表支持 `?has_evidence=0|1`
4. `scripts/m22-accept.mjs`

## 明确不做

- 真支付 / WhatsApp / 新退款渠道
- 复杂审批流、多级会签
- 改会员申请页（证据仍可选；退货通过时后台拦截）
