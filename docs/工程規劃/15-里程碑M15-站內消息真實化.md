## 背景

M7 已提供雙列表 UI + 未讀紅點，但 API 走 `MockMarketingService`（`mock: true`）。  
M11–M14 已把秒殺 / 積分商城 / 分銷 / 簽到做實；消息是剩餘的主鏈 Mock 能力之一。

## 目标（已完成）

1. 真實表 `member_messages`；訂單狀態變更自動寫入「訂單消息」  
2. 系統消息可由後台發布；seed 歡迎條；會員列表 / 已讀 / 未讀數讀庫  
3. H5 消息頁去掉 Mock 橫幅；`mock: false`  
4. REST `/api/v1/messages*` 契約兼容（字段可擴）

## 实现说明

### 表

- 单表 `member_messages`（不拆 order/system 表）
- 幂等：`(member_id, event_key)` 唯一，重入支付确认不重复写

### 订单事件

| event_key 后缀 | 触发 |
| --- | --- |
| `created` / `created_zero` | 下单成功（零元单走 created_zero） |
| `paid` | mock/回调确认支付 |
| `shipped` | 后台发货 |
| `completed` | 确认收货 |
| `cancelled` | 取消 / 超时关单 |
| `refunded` | 整单退款完成 |

售后审核：`aftersale:{id}:approved|rejected|completed`（落在订单消息 Tab，可跳转订单）。

### API

- `GET /api/v1/messages`、`/messages/unread-count`、`POST /messages/read`（`id` / `ids` / `all`）
- `GET|POST /api/v1/admin/messages`（系统广播；可选 `member_id`）

### 前端

- H5：去掉 Mock 横幅；继续用 `m7.ts` 契约
- Admin：內容 → 消息（列表 + 新建）
