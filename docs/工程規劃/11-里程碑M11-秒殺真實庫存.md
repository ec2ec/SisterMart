# M11 — 秒殺真實活動庫存

| 项 | 内容 |
| --- | --- |
| 状态 | **实现完成，待联合检查** |
| 前置 | M10 适配层已落地；**真支付 / 合規商戶申請暫停**，繼續 `PAYMENT_MODE=mock` |
| 原则 | 秒殺場次與活動庫存走真實表扣減；支付仍用 Mock |
| 后续 | **M12 積分商城真實兌換** |

## 目标

把 M7 Mock 秒殺改為可下單、可扣庫存、關單可回補的真實活動庫存。

## 交付物

1. 表 `seckill_sessions` / `seckill_items`；`orders.seckill_item_id`  
2. `SeckillService` + `GET /api/v1/seckill/*` 讀庫  
3. 結算 `quote` / `create` 支援 `seckill_item_id`（限購 1、秒殺價、雙扣 SKU + 活動庫存）  
4. 超時/取消關單回補活動庫存  
5. H5 秒殺列表/詳情/商品詳情 → checkout 帶 `seckill_item_id`  
6. `database/m11_seckill.sql` + `m11_seed.php`  

## 验收清单

1. `GET /seckill/sessions` 返回進行中/預告場次，`mock: false`  
2. 進行中商品可 `POST /checkout/quote` + `create`，`orders.seckill_item_id` 有值，`seckill_items.stock` 減少、`sold` 增加  
3. 未開始場次下單 → `SECKILL_NOT_LIVE`  
4. 庫存為 0 → `OUT_OF_STOCK`  
5. 待付款超時關閉後活動庫存回補  
6. 支付仍可走 mock-confirm  

## 明确不做（本里程碑）

- 不申請 SVF/MSO、不對接聚合收單、不切 `PAYMENT_MODE=live`  
- 不做秒殺後台 CRUD（種子數據驗收即可）  
- 不做積分商城 / 分銷真實化
