# 里程碑 M0–M9（简档）

状态：**路线图冻结（M0）**  
原则：先模具与契约，后业务；一期 Mock 的能力不得在文档未修订前升级为真实实现。

> **里程碑真源（门禁细则）**：[`05-里程碑拆分与验收门禁-详细版.md`](./05-里程碑拆分与验收门禁-详细版.md)。  
> 若本简档与详细版冲突，**以详细版 + 会话交接索引 + PRD 为准**。M0 关闭声明与 [`../验收/M0-关闭记录.md`](../验收/M0-关闭记录.md) 仍有效。

| 里程碑 | 目标 | 退出标准（摘要） |
| --- | --- | --- |
| **M0** | Monorepo 模具 + 技术/范围/里程碑冻结 | 目录齐全；冻结文档入库；`main` 已 push；远程文件树可核对。**关闭：本里程碑完成即关闭。** |
| **M1** | API / H5 / Admin 脚手架可启动 | ThinkPHP 8.1、Vue3+Vant4、Vue3+NaiveUI 空应用可本地跑通；健康检查可用 |
| **M2** | 基础工程与环境 | MySQL 连接、环境变量、统一错误码/日志、CI 初稿 |
| **M3** | 邮箱登录与账号会话 | 注册/登录/登出/会话校验；三端联调通过验收用例 |
| **M4** | 商品与目录（2.7 相关） | 商品/分类等一期后端读写；H5 浏览、Admin 维护 |
| **M5** | 订单与模拟支付（2.8 相关） | 下单、支付回调模拟、订单状态机；无真实渠道 |
| **M6** | 秒杀 / 分销 Mock | 约定 Mock 接口与前端联调；不落真实库存抢购与分佣结算 |
| **M7** | 双语与运营配置 | `zh-HK` / `en` 贯通 H5/Admin；文案与关键配置可维护 |
| **M8** | 验收加固 | 按 `docs/验收` 跑通一期主路径；缺陷收敛 |
| **M9** | 一期交付冻结 | 文档与代码对齐；发布清单；后续增强（真支付/真秒杀/真分销）另开里程碑 |
