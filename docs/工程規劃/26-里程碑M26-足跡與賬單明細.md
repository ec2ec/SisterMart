## 目标

按 PRD §16：登录浏览详情写入**足迹**（同商品只保留最近一次）；**账单明细**展示余额流水（下单扣余额、佣金转入、退款入帐、关单退回等）。无充值。

## 范围

1. 表 `browse_history` + `BrowseHistoryService`
2. 带会员 Bearer 的 `GET /products/:id` 自动 touch 足迹
3. `GET/DELETE /browse-history`（清空 / 删单条）
4. H5：`FootprintView`、`BalanceLogsView`；我的页入口；余额数字点进账单
5. 既有 `GET /balance-logs` 接前台
6. `scripts/m26-accept.mjs`

## 明确不做

- 真支付 / WhatsApp
- 收藏服务端化（仍为本地 favorite）
- 首页「猜你喜欢」接足迹分类（方法已预留 `recentCategoryIds`）
