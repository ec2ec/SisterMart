# 香港合規聚合收單／網關推薦（SisterMart）

> 非投資／商務背書。選定前請自行核對牌照、合約費率、結算週期與「是否支援 **線上 API／異步回調**」。  
> 目標：一次簽約覆蓋 **FPS + AlipayHK + WeChat Pay HK**（最好再含卡），對接本系統 M11。

---

## 1. 先搞清楚「合規」指什麼

香港收款方常見監管身分（可並存／透過合作銀行落地）：

| 類型 | 監管 | 查冊 |
| --- | --- | --- |
| **持牌銀行** | 《銀行業條例》／金管局 | 金管局銀行名冊 |
| **SVF 持牌人**（儲值支付工具） | 《支付系統及儲值支付工具條例》 | [金管局 SVF 紀錄冊](https://www.hkma.gov.hk/chi/regulatory-resources/registers/register-of-svf-licensees/) |
| **MSO**（金錢服務經營者） | 香港海關 | [MSO 查冊](https://eservices.customs.gov.hk/MSOS/wsrh/001s1) |

**詢價時必問：**

1. 你們是銀行收單、SVF、還是技術服務商＋銀行／持牌人合作？牌照號？  
2. 資金是否 **settlement 到我司香港銀行戶口**？誰是收單主體？  
3. 是否提供 **Website/H5/App API + server-to-server webhook**（不要只給門店碼）？  
4. FPS / AlipayHK / WeChat Pay HK 是否 **同一商戶合約內全部可開**？沙盒有無？  
5. 費率、退款費、押金、結算 T+?、凍結期、禁止類目？

官方錢包本身也是 SVF：AlipayHK = **SVF0004**；WeChat Pay HK = **SVF0005**（以金管局最新紀錄為準）。

---

## 2. 推薦優先級（針對自建電商如 SisterMart）

### A. 首選：持牌銀行「一站式商戶／網上支付網關」（合規最清晰）

適合：已有／願意開該行公司戶；要長期穩定、對賬簡單。

| 機構 | 公開能力摘要（以官網為準） | 聯絡／入口 |
| --- | --- | --- |
| **滙豐 HSBC Digital Merchant Services** | 一站式：Visa/MC/銀聯/Amex、**轉數快**、PayMe、**支付寶香港**、支付寶、**微信支付**、Apple/Google Pay | [產品頁](https://www.business.hsbc.com.hk/zh-hk/products/hsbc-digital-merchant-services) → 找客戶經理 |
| **建行（亞洲）龍支付 HK / 網上支付網關** | 聚合碼（FPS／銀聯／微信等）；網上網關公開寫明支援卡、**FPS**、**微信支付**（官網稱支付寶等將陸續加入，簽約時務必書面確認 AlipayHK） | [商戶服務](https://www.asia.ccb.com/hongkong_tc/commercial/merchant-management.html) |
| **東亞銀行 BEA 商戶電子收款** | 終端／網上網關；含 FPS 等（以最新產品冊為準） | 商戶熱線見銀行商戶 FAQ |

**優點：** 資金路徑清楚、合規敘事簡單、對大額／品牌站友好。  
**代價：** KYC 嚴、審批較慢、可能要求在該行開戶。

### B. 次選：成熟本地／區域網上支付網關（電商 API 成熟）

適合：要快對接 H5、文檔齊、一次開多錢包。

| 機構 | 公開能力摘要 | 入口 |
| --- | --- | --- |
| **AsiaPay / PayDollar** | 香港註冊商戶網上收款；公開支援卡、**FPS**、**Alipay／AlipayHK**、**WeChat Pay**、PayMe、八達通等；有 API／SDK／開發者文檔 | https://www.paydollar.com/ · https://www.asiapay.com/ |
| **QFPay（錢方）** | 香港 openapi；Checkout／Element SDK；文檔列 **Alipay／AlipayHK、WeChat、FPS、PayMe、卡、Apple Pay** 等 | https://sdk.qfapi.com/ · https://openapi-hk.qfapi.com/ |
| **Yedpay** | 香港網上支付 API／Checkout link；文檔含 Alipay／WeChat／卡等閘道碼（簽約時確認 FPS 線上產品） | https://api.yedpay.com/ |
| **eftPay** | 本地聚合支付／網關文宣含 AlipayHK、WeChat、FPS、卡、八達通等（偏中小企；務必核對牌照與結算主體） | https://www.eftpay.com.hk/ |

**優點：** 對自建站友好、聯調快。  
**注意：** 確認對方是 **持牌收單／與持牌機構合作**，並要書面「結算主體＋牌照號」。

### C. 直連錢包（非聚合，但合規主體最「正」）

若聚合談不攏，可拆開申請（見 `09-香港三渠道支付商戶申請流程.md`）：

- FPS → 開戶銀行／SVF  
- AlipayHK → Alipay Financial Services (HK)（SVF0004）  
- WeChat Pay HK → WeChat Pay Hong Kong Limited（SVF0005）  

工作量大（三套 KYC／三套 API），但合規主體清晰。

## 3. SisterMart 實務建議（怎麼選）

| 情境 | 建議 |
| --- | --- |
| 已有匯豐／建行等公司戶 | **先問本行 Digital Merchant／網上支付網關**，一次開三錢包＋卡 |
| 想最快對接自建 H5、要齊全文檔 | 並行詢價 **AsiaPay PayDollar、QFPay**，比較費率／結算／沙盒 |
| 只要線下碼 | **不要用**這條當本站主收款 |
| 最終決策 | 至少要 2 家書面報價 + 牌照／結算主體說明 + 測試商戶 |

詢價郵件可附：`https://sistermart.vip`、預估月 GMV、需要 **server 回調**、渠道清單 FPS/AlipayHK/WeChatHK（可加 Visa/Mastercard）。

---

## 4. 與本倉庫銜接

- M10：已有可插拔 `PaymentChannel`；可先做「聚合網關 Adapter」一個，而不是三個直連。  
- M11：選定供應商後，把商戶號／密鑰填入 `PAYMENT_*` 或新增 `PAYMENT_GATEWAY_*=`。  
- 切 `PAYMENT_MODE=live` 前必須沙盒全過：下單→支付→回調→`pending_shipment`→退款（若有）。

---

## 5. 官方查冊（簽約前必做）

1. 金管局 SVF：https://www.hkma.gov.hk/chi/regulatory-resources/registers/register-of-svf-licensees/  
2. 海關 MSO：https://eservices.customs.gov.hk/MSOS/wsrh/001s1  
3. FPS 參與機構：https://www.hkicl.com.hk/eng/fps/about_fps/participant.php  

若對方無法提供可核對的牌照／合作銀行收單證明，**不建議接入**。
