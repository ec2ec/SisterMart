# H5 UI 库选型对比（Vue 3 SPA）

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-10-14 |
| 场景 | SisterMart 香港珠宝 H5 商城（Vue 3 SPA，非小程序多端） |
| 对比对象 | **Vant 4** vs **NutUI**（市面最成熟的两款 Vue3 移动端库） |
| 结论 | **选型：Vant 4** |

数据截至调研时（GitHub）：Vant ≈ 24.4k★ / 近期仍活跃；NutUI（jd-opensource/nutui）≈ 6.5k★。

---

## 1. 为什么只比这两款

面向 **Vue 3 + 纯 H5 SPA + 电商交易流** 时，国内开源里长期维护、组件覆盖完整、社区验证充分的主流就是：

| 库 | 出品 | 定位 |
| --- | --- | --- |
| **Vant 4** | 有赞 | 通用移动端组件库，电商场景组件极全 |
| **NutUI** | 京东 | 京东设计语言，偏多端（H5/小程序/App） |

其他如 Varlet、wot-design-uni、Cube UI 等：要么生态更小，要么绑定 uni-app，不作为本期首选对比。

后台已定为 **Naive UI**，与 H5 库无关，不混用。

---

## 2. 对照表

| 维度 | Vant 4 | NutUI | SisterMart 相关性 |
| --- | --- | --- | --- |
| 框架 | Vue 3，长期支持 | Vue 3（亦有多端线） | 都满足 |
| 体积/依赖 | 官方宣称组件平均 &lt;1KB gzip，**零三方依赖** | 体积可控，按需加载 | H5 弱网友好 → Vant 略优 |
| 电商组件 | **Sku、SubmitBar、AddressList/Edit、Coupon、Card、SwipeCell** 等开箱即用 | 有 Price、Address 等，电商专用组合略少于 Vant | 购物闭环直接相关 → **Vant 明显更贴** |
| 图片预览 | `ImagePreview` 支持手势缩放、滑动切换 | 有 ImagePreview | 对应 PRD 全屏看图 |
| 国际化 | 内置 30+ 语言包，易接 zh-HK / en | 支持 i18n | 一期双语 → 都可；Vant 文档与包更熟 |
| 主题定制 | 700+ CSS 变量，易换珠宝品牌色 | 支持主题 / 暗色 | 都可；需避开「有赞橙/京东红」默认感 |
| 文档与示例 | 中英文档、示例极全，脚手架生态多 | 文档完整，京东风示例多 | 交付速度 → Vant |
| 社区与活跃 | Star/生态最大，推送活跃（调研时近一周有提交） | 活跃但体量与更新节奏弱于 Vant | 排障与招人 → Vant |
| 多端 | 另有小程序版，**但 H5 主库不绑 Taro** | 强项在多端统一 | 本期只要 H5 SPA → **不需要 NutUI 多端优势** |
| 视觉默认 | 有赞风，偏通用电商 | 京东风，偏平台电商 | 珠宝品牌都要定制主题，默认皮可覆盖 |

## 3. 与 PRD 页面映射（抽样）

| PRD 能力 | Vant 首选组件 | NutUI |
| --- | --- | --- |
| 底栏四键 | `Tabbar` | `Tabbar` |
| 顶栏搜索/消息红点 | `NavBar` + `Search` + `Badge` | `Navbar` + `Searchbar` + `Badge` |
| 首页轮播/宫格 | `Swipe` + `Grid` | `Swiper` + `Grid` |
| 商品卡角标/收藏 | `Tag` + `Icon` | `Tag` + `Icon` |
| SKU 选择 | **`Sku`** | 需组合弹层+规格，工作量更大 |
| 加购/立即购买底栏 | **`SubmitBar` / `ActionBar`** | 组合实现 |
| 地址簿 | **`AddressList` / `AddressEdit`** | 有地址相关，完整度略逊 |
| 优惠券 | **`Coupon` / `CouponList`** | 需更多自研 |
| 全屏看图缩放 | `ImagePreview` | `ImagePreview` |
| 分享 | `ShareSheet` | 弹层自组 |
| 步骤/物流 | `Steps` | `Steps` |

一期要做购物闭环 + 券/地址/SKU：**Vant 能少写大量胶水代码**。

## 4. 风险与规避

| 风险 | 说明 | 规避 |
| --- | --- | --- |
| 「千店一面」有赞皮 | 默认主题像有赞商城 | 立项即定品牌色/圆角/字号 token，覆盖 CSS 变量 |
| 繁中香港 | 内置多为 zh-CN | 业务文案走项目 i18n（zh-HK）；组件库次要文案可覆写 |
| 珠宝气质 | 组件偏零售工具感 | 商品卡、详情、首页区块可自研布局，表单/弹层/导航用 Vant |

NutUI 主要风险：多端能力用不上；电商专用组件少于 Vant；社区体量较小，招人与排障成本略高。

---

## 5. 选型结论（冻结建议）

### 采用：**Vant 4**（`vant` 最新 4.x）

**理由（针对 SisterMart）：**

1. 纯 H5 SPA，不需要 NutUI 的小程序/多端故事。  
2. Sku / 地址 / 优惠券 / SubmitBar 与一期闭环高度重合，缩短工期。  
3. 生态、文档、长期支持与活跃度更稳。  
4. 零依赖、按需引入，适合香港移动网络场景。  
5. 品牌差异靠主题变量 + 自研首页/商品卡视觉解决，不靠换组件库。

### 明确不选 NutUI 的原因

- 优势集中在「京东风 + 多端」，与本期架构不匹配。  
- 同等电商闭环下，自研/拼装成本更高。

### 配套约定

| 项 | 约定 |
| --- | --- |
| 安装 | `apps/h5` 内 `vant` + 按需引入（unplugin-vue-components） |
| 主题 | 建立 SisterMart Design Token，覆盖 Vant 变量 |
| i18n | 业务文案项目内维护 zh-HK / en；Vant Locale 同步切换 |
| 自研边界 | 珠宝感强的商品卡、首页楼层可自研；交互底座用 Vant |
| 后台 | 继续 **Naive UI**，与 H5 分离 |
