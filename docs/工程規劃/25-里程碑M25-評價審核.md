## 目标

评价内容**作者本人始终可见**（无论待审 / 拒绝）；**他人仅在审核通过后**才在商品详情看到。

## 范围

1. 列：`moderation_status`（`pending` / `approved` / `rejected`）
2. 新建主评 → `pending`；追评 → 整条重回 `pending`
3. 历史行种子回填为 `approved`
4. `listForProduct`：公开仅 `approved` 且未隐藏；带会员 token 时额外含本人全部状态
5. `GET /api/v1/products/:id` 可选 Bearer
6. Admin：`POST …/reviews/:id/moderate` + 列表筛审 + UI 通过/拒绝
7. H5 PDP：本人待审/拒绝角标；`fetchProduct` 带会员 token
8. `scripts/m25-accept.mjs`；同步调整 m18/m23 验收对公开可见性的假设

## 明确不做

- 真支付 / WhatsApp
- 敏感词自动审、删改会员正文
