# 香港三渠道支付商戶申請詳細流程

> 適用於 SisterMart 二期（M10/M11）接通 **FPS / AlipayHK / WeChat Pay HK**。  
> 說明以官方公開資訊為準；費率、審批時間、所需文件會因銀行／服務商而異，以對方合約為最終依據。  
> **電商網站必須申請「線上／API／網關」能力**，不要只申請「門店二維碼收款」（那無法對接本系統回調）。

---

## 0. 申請前先備齊（三渠道通用）

| 類別 | 通常需要 |
| --- | --- |
| 公司資格 | 有效 **商業登記證 BR**；有限公司另備 **公司註冊證明書 CI**／周年申報表 |
| 負責人 | 董事／實益擁有人 **身份證明**；無限公司需法人資料；授權代表需授權書 |
| 結算戶口 | 香港公司／個人銀行戶口證明（銀行卡／存摺副本、近 **3 個月**月結單） |
| 業務證明 | 網店網址（如 https://sistermart.vip）、商品類別、預計交易量、聯絡人電郵／電話 |
| 合規 | KYC／AML 問卷；部分行業（高風險）可能被拒或加審 |

**對本專案最關鍵的一句話：**  
申請時明確告訴對方要 **「Online / Website / App / API / Gateway / Web-to-App」**，並提供回調域名（例如 `https://sistermart.vip/api/index.php/api/v1/payment-callbacks/{channel}`）。

## 1. 轉數快 FPS（Faster Payment System）

### 1.1 你要知道的結構

- **HKICL** 只提供 FPS 平台，**不直接向商戶簽約**。
- 商戶必須向 **參與銀行** 或 **SVF（儲值支付工具，如部分錢包運營商）** 申請「商戶收款／FPS 商戶服務」。
- FPS 平台本身對商戶不收費；**銀行／SVF 會收服務費**，條款各異。
- 電商需要的是支援 **App-to-App / Web-to-App（ATA/WTA）** 或銀行提供的 **FPS 商戶 API／QR API**，而不是只拿一個靜態個人 FPS ID。

官方 FAQ：https://fps.hkicl.com.hk/eng/fps/merchants/frequently_asked_questions.php

### 1.2 推薦申請路徑（選一）

**路徑 A — 開戶銀行直接申請（適合已有公司戶口）**

1. 聯絡你現有銀行的「商戶服務／電子收款／Merchant Services」。  
2. 說明業務：H5 電商、需要 FPS 網上收款 + 異步通知。  
3. 提交 BR／CI、董事證件、公司戶口、網店資料。  
4. 銀行審批 → 開通商戶號／FPS Merchant ID。  
5. 索取：**商戶號、簽名密鑰／證書、下單與查單 API 文檔、回調驗簽說明、沙盒環境**。  
6. 把密鑰填入本系統環境變量（見 `docs/接口/M10-支付渠道适配.md` 的 `PAYMENT_FPS_*`）。

常見可詢問的銀行／機構（以對方是否仍提供「網上 FPS 商戶 API」為準）：  
HSBC、恒生、渣打、中銀香港、東亞、HKT Merchant / Tap & Go 等。

**路徑 B — 聚合支付／網關（適合想一次開通多渠道）**

1. 選擇同時支援 FPS + AlipayHK + WeChatHK 的香港收單／網關（銀行附屬或獨立 PSP）。  
2. 提交同一套 KYC 文件。  
3. 簽約後拿 **統一商戶後台 + API Key**，本系統對接該網關即可（不一定直連三家）。  

**路徑 C — 僅門店 FPS QR／FPS ID（不建議作為 SisterMart 主路徑）**

- 申請快（有的 7 個工作天左右），但多為掃碼／展示碼，**難做自動對賬與訂單回調**。  
- 可作線下備份，不能替代本站 `#/payment` 閉環。

### 1.3 典型時間線

| 步驟 | 內容 | 粗估 |
| --- | --- | --- |
| 1 | 選定銀行／SVF／網關並填申請表 | 1–3 天 |
| 2 | 補件＋KYC | 3–10 個工作天 |
| 3 | 開通商戶＋發 API／證書 | 視機構 1–4 週 |
| 4 | 沙盒聯調 → 切生產 | 本專案 M11 開發週期 |

### 1.4 接通後你應拿到的東西（給開發）

- Merchant / FPS ID  
- Client secret 或簽名字典／證書  
- 下單、查單、退款 API  
- Webhook／回調 URL 配置入口  
- 測試環境帳號

## 2. AlipayHK（支付寶香港）

### 2.1 兩種能力，不要搞混

| 類型 | 用途 | SisterMart |
| --- | --- | --- |
| **商戶碼／門店碼** | 店舖展示二維碼收款 | ❌ 不夠（無訂單級回調） |
| **網店／線上收款／系統對接** | API、H5、App、聚合 POS | ✅ 必須這個 |

官方商戶 FAQ：https://www.alipayhk.com/merchants/setup-and-support/frequently-asked-questions/  
網上申請入口（官方公布）：https://s.alipay.hk/7MWapx  
商戶熱線：**+852 2245 3201**（每日約 09:00–21:00）

### 2.2 詳細申請流程（線上電商）

1. **選方案**  
   - 只開店舖碼 → 可直接網頁申請。  
   - **網店／要對接現有系統（本專案）→ 致電 2245 3201**，說明要「網店收款／API／與自建系統對接」，由商戶服務介紹服務商或直連方案。

2. **提交申請資料（一般）**  
   - 有效 BR、CI  
   - 銀行戶口資料（卡／存摺副本 + 近 3 個月月結單）  
   - 公司業務與產品信息、網址  
   - 無限公司：法人資料  
   - 對方可能再要：股權結構、實益擁有人證件、店照／網站截圖等  

3. **審批與簽約**  
   - 商戶服務團隊跟進審批。  
   - 入駐簽約後開通「商家運營中心」平台帳號（公開文檔稱正常約 **3–5 個工作天** 開通登入郵件）。  
   - 首次登入設置登入密碼與支付密碼。  

4. **技術開通**  
   - 向對方索取：**PID／AppId、商戶私鑰、支付寶公鑰、網關地址、異步通知驗簽文檔、沙盒**。  
   - 配置回調 URL，完成聯調。  
   - 填入本系統 `PAYMENT_ALIPAY_HK_*`。

### 2.3 典型時間線

| 步驟 | 粗估 |
| --- | --- |
| 網申／熱線建檔 | 1–2 天 |
| KYC 審批與簽約 | 數天至數週（視補件） |
| 運營中心帳號開通 | 約 3–5 個工作天（收齊資料後） |
| API 開通與聯調 | 視服務商／直連路徑 |

### 2.4 注意

- 「商戶碼申請通過」≠「線上 API 已開通」。務必書面確認 **線上支付產品** 已啟用。  
- 費率、結算週期、退款規則以合約為準。

## 3. WeChat Pay HK（微信支付香港）

### 3.1 兩種申請入口

官方商戶頁：https://pay.wechat.com/zh_hk/merchant.shtml  
商務電郵：**hkpayment@wechat.com**  
熱線（頁面公布）：**+852 3929 1666**

| 入口 | 適合 | SisterMart |
| --- | --- | --- |
| **收款碼小程序** | 門店展示 QR，審批後可能上門協助佈置 | ❌ 僅線下碼不夠 |
| **電郵／人工協助** | POS、**線上支付（小程序／網頁／App）** | ✅ 必須走這條 |

### 3.2 詳細申請流程（線上支付）

1. **準備電郵申請表**（按官方頁提示複製填寫），至少包含：  
   - 商戶名稱  
   - 聯絡人、手機  
   - 地址  
   - 所屬行業（餐飲／零售／其他）  
   - 門店數量（網店可寫 0／線上）  
   - **希望採用的支付方式：勾選「線上支付（小程式、網頁支付、App 支付等）」**  

2. **發送至** `hkpayment@wechat.com`，並附上：  
   - BR、CI／周年申報  
   - 負責人／實益擁有人身份證明（申請人須為實益擁有人或獲授權代表）  
   - 銀行戶口證明  
   - 網店網址與業務說明  

3. **跟進審批**  
   - 對方回覆後補 KYC、簽約。  
   - 結算戶口需為支援 WeChat Pay HK 的銀行戶口（公開資料常提及如匯豐、渣打、恒生等，以對方最新名單為準）。  

4. **技術開通**  
   - 索取：**mch_id、app_id、API key／證書、支付與回調文檔、測試環境**。  
   - 配置回調，聯調成功後填入 `PAYMENT_WECHAT_HK_*`。  

### 3.3 門店碼路徑（僅作參考，非本站主路徑）

1. 用微信打開 WeChat Pay HK 收款碼相關小程序並填表。  
2. 審批通過後可能安排到店協助。  
3. 展示靜態／半靜態碼收款 —— **無法直接替代本系統訂單回調**。  

### 3.4 典型時間線

| 步驟 | 粗估 |
| --- | --- |
| 電郵建檔 | 1–3 天 |
| KYC＋簽約 | 數天至數週 |
| 線上產品與密鑰下發 | 視審批 |
| 聯調上線 | M11 開發週期 |

## 4. 建議的整體策略（SisterMart）

```text
方案 A（推薦起步）：找一家香港聚合收單／網關
  → 一次 KYC 同時開 FPS + AlipayHK + WeChatHK
  → 本系統對接「一個網關 API」即可（改 Factory 內一個 Adapter）

方案 B（直連）：分別向銀行申請 FPS、向 AlipayHK / WeChat Pay HK 申請線上產品
  → 三套密鑰、三套回調驗簽
  → 對應 M11 三個渠道實作
```

### 申請時對商務話術（可直接用）

> 我們是香港電商網站 SisterMart（https://sistermart.vip），需要 **線上 API／網頁支付**，顧客在 H5 選擇 FPS / AlipayHK / WeChat Pay HK 後完成支付，並透過 **HTTPS 異步通知** 更新訂單狀態。請提供商戶號、簽名密鑰／證書、沙盒與回調驗簽文檔。
