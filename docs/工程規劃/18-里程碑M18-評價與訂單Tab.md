## 范围（两块）

### A. 商品評價（主評 + 追評）

1. 新表 `product_reviews`：一筆對應一個 `order_item_id`（主評唯一）  
2. **主評**：已完成訂單、該行未全額退款、尚未評價 → 星級 1–5、文字、圖片最多 3 張（≤1MB）  
3. **追評**：主評後可追評一次（僅文字）；不可改星級  
4. 商品詳情 `GET /products/:id` 的 `reviews` 改為讀庫（最新在前）  
5. 訂單詳情行項帶 `can_review` / `review_id` / `can_follow`；已完成未評顯示「去評價」  

### B. 我的訂單列表 Tab

列表 Tab：**全部 / 待付款 / 待發貨 / 待收貨 / 待評價 / 售後**

| Tab | API `?status=` | 規則 |
| --- | --- | --- |
| 全部 | （空） | 該會員全部訂單 |
| 待付款 | `pending_payment` | 狀態篩選 |
| 待發貨 | `pending_shipment` | 狀態篩選 |
| 待收貨 | `pending_receipt` | 狀態篩選 |
| 待評價 | `to_review` | `status=completed` 且仍有可評行項（未全退且無主評） |
| 售後 | `aftersale` | `aftersale_touched=1` |

「我的」快捷入口：待付款/待發貨/待收貨/待評價帶對應 query；售後仍進售後列表。

## 实现要点

### API / DB

| 交付 | 说明 |
| --- | --- |
| `m18_reviews.sql` / `m18_seed.php` | 建表 + storage 目錄 |
| `ReviewService` | create / follow / listForProduct / flagsForOrderItems |
| `POST /api/v1/reviews` | 主評 |
| `POST /api/v1/reviews/:id/follow` | 追評 |
| `POST /api/v1/uploads/review-image` | 評價圖上傳（ImageUploadService preset=review） |
| `POST /api/v1/admin/uploads/image` | 後台通用圖上傳（preset / max_edge / quality 可配） |
| `ImageProcess` / `ImageUploadService` | 通用等比壓縮（JPG，可配邊長與質量） |
| `OrderService::listForMember` | 支持 `to_review` / `aftersale` |
| `OrderService::presentDetail` | 行項評價標記 |
| `CatalogService` | `reviews` 讀庫 |

## 验收清单

| # | 项 |
| --- | --- |
| 1 | 未完成訂單不可主評（API 422） |
| 2 | 完成訂單可主評；同一 order_item 不可重複主評 |
| 3 | 主評後可追評一次；再次追評拒絕 |
| 4 | `GET /products/:code` reviews 含剛寫入的評價 |
| 5 | `?status=to_review` 僅返回仍有未評行的已完成單；評完後消失 |
| 6 | `?status=aftersale` 僅 aftersale_touched 訂單 |
| 7 | 評價圖上傳 ≤5MB；服務端壓成最長邊 ≤1200 的 JPG 且 ≤500KB；第 4 張攔截 |
| 8 | 商品詳情評價圖為縮略圖，點擊全屏預覽 |
