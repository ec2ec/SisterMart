# M12 — 積分商城真實兌換

| 项 | 内容 |
| --- | --- |
| 状态 | **已关闭** |
| 前置 | M11 秒殺真實庫存；**支付繼續 mock**（製度/真渠道仍暫緩） |
| 原则 | 積分商品單獨下單；扣積分 + SKU/活動庫存；運費按現金規則可 mock 支付 |
| 后续 | **M13 一級分銷真實化** |

## 目标

把 M7 Mock 積分商城改為可兌換、可扣庫存、關單退積分的真實流程（對齊 PRD §12.3）。

## 交付物

1. 表 `points_mall_items`；`orders.points_mall_item_id`  
2. `PointsMallService` + `GET /api/v1/points-mall/products*`  
3. 結算支援 `points_mall_item_id`（不用券/餘額/現金購貨；運費可付現金）  
4. 關單回補活動庫存並退回兌換積分；完成時不發下單積分  
5. H5 積分商城 → checkout  
6. `m12_points_mall.sql` + `m12_seed.php`  

## 验收清单

1. 列表/詳情 `mock: false`  
2. 積分足夠可下單：`points_used` = 兌換積分，`points_mall_item_id` 有值，庫存下降  
3. 積分不足 → `POINTS_SHORT`；售罄 → `OUT_OF_STOCK`  
4. 取消/超時關單：積分與活動庫存回補  
5. 運費 > 0 時可走 mock 支付；運費 = 0 時直接待發貨  
6. 確認收貨不發 `order_earn` 積分  

## 明确不做

- 不接真支付、不做分銷真實化、不做積分商城後台 CRUD（種子驗收）
