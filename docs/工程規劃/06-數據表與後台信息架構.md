# 數據表與後台信息架構

狀態：2026-10-14 規劃。本文件是一期表結構與後台頁面的對照；與 PRD v1.4、`05-里程碑拆分与验收门禁-详细版.md` 衝突時，以那兩份為準。

這一輪只落庫並實現 **M2**：會員 Token 登錄、驗證碼占位、底欄配置。M3 及之後的表寫在這裡，等對應里程碑再遷移，避免空表先上線。

## 1. 和 Bagisto 的關係

Bagisto 只借用後台的側欄分組和「列表篩選 + 編輯頁」習慣，對照 `packages/Webkul/Admin/src/Config/menu.php`。SisterMart 不是 Bagisto 分叉，不搬這些模塊：

- EAV 屬性族、屬性集
- 多渠道、多貨幣、匯率
- 稅、發票、交易流水、預訂、GDPR
- 目錄促銷規則 / 購物車規則引擎（優惠券按 PRD 自建）
- 主題市場

數據也不跟 Bagisto 的 EAV。雙語用 `*_i18n` 子表，`locale` 只允許 `zh-HK` 與 `en`。金額 `DECIMAL(12,2)`，貨幣只有 HKD。積分用整數。

## 2. 後台頁面結構

側欄按 Bagisto 的組來收 PRD §18。路由掛在 `apps/admin`，這一輪全部可點：只有登錄和底部導航是真頁面，其餘進占位頁，文案說明開放里程碑。

| 側欄組（對照 Bagisto） | 菜單 | 路由 | 開放 |
| --- | --- | --- | --- |
| Dashboard | 概覽 | `/` | 本輪只顯示接口健康與當前管理員，業務數字後續再接 |
| Catalog | 商品 | `/catalog/products` | M3 |
| Catalog | 分類 | `/catalog/categories` | M3 |
| Sales | 訂單 | `/sales/orders` | M4 |
| Sales | 售後 | `/sales/aftersales` | M5 |
| Customers | 會員 | `/customers/members` | 會員等級一期要做，頁面隨積分／餘額里程碑 |
| CMS | 文章 | `/cms/articles` | M3（協議、頁腳） |
| CMS | 首頁 | `/cms/home` | 首頁運營塊 |
| CMS | 消息 | `/cms/messages` | 系統／營銷消息 |
| Marketing | 優惠券 | `/marketing/coupons` | 一期後端 |
| Marketing | 積分 | `/marketing/points` | 一期後端 |

H5 令牌與管理員令牌分開（PRD §19）。角色至少兩種：`super`、`ops`。本輪兩種角色都能改底欄；菜單級權限隨設置模塊再收緊。

列表頁以後統一：狀態、時間、關鍵字篩選，分頁。編輯頁左表單、右預覽或說明，不做成 Bagisto 那種屬性族向導。

## 3. 本輪要建的表（M2）

腳本：`apps/api/database/m2_auth_tabbar.sql`。

### members

| 列 | 說明 |
| --- | --- |
| id | 自增，從 1001 起，推廣號寫成 `SM1001` |
| email | 可空，唯一，小寫 |
| phone | 可空，唯一，規範成 `+852` 加 8 位 |
| password_hash | `password_hash` |
| locale | `zh-HK` 或 `en` |
| promo_code | 唯一推廣號 |
| parent_id | 註冊時的上級，已有上級不再改 |
| status | 1 正常，0 停用 |
| agreed_terms_at | 勾選協議的時間 |
| created_at / updated_at | |

### member_tokens / admin_tokens

不透明令牌，庫裡只存 SHA-256。明文只在登錄時返回一次。30 天過期。退出刪掉當前這條，所以可以作廢。H5 用 `Authorization: Bearer`，鍵名與後台令牌互不通用。

### verify_codes

`channel` 為 `email` 或 `whatsapp`，`purpose` 為 `register`、`login`、`reset`。存驗證碼哈希、6 位、10 分鐘、最多 5 次。同一目標 60 秒內不重發。

WhatsApp **不實發**。註冊時接口直接返回 `WHATSAPP_UNAVAILABLE`，頁面改填郵箱再發郵件。登錄和重設密碼時，WhatsApp 失敗後改發到已綁定郵箱。`APP_DEBUG=true` 時響應帶 `debug_code`，並寫入日誌，方便本機不用 SMTP。

### admins / admin_roles

種子：`admin@sistermart.local` / `admin123456`，角色 `super`。另有 `ops` 角色行，尚無對應帳號。

### tabbar_items

主鍵是槽位，只有 `home`、`category`、`cart`、`account`。後台不能增刪槽位，也不能改跳轉頁。每行：繁中文案、英文文案、未選中／選中圖標、圖標圓底色、文字色。圖標這一輪填 Vant 圖標名或圖片 URL；上傳文件隨 M3 媒體一起做。

### shop_settings

`setting_key` / `setting_value`。本輪只種子 `tabbar.bar_bg`。以後同一張表放包郵門檻、運費、未支付關閉分鐘、自動收貨天數、已售精確或模糊、最低提現額、客服 WhatsApp、驗證碼 WhatsApp、支付參數。

## 4. 本輪接口

嚴格遵守 `docs/接口/00-接口约定.md`：路徑為 `/api/v1` 資源名，響應為 `{ code, message, data }`，成功時 `code === 0`。

| 方法 | 路徑 | 說明 |
| --- | --- | --- |
| POST | `/api/v1/verification-codes` | 發驗證碼。郵件寫日誌；WhatsApp 按上面的規則失敗或改發郵件 |
| POST | `/api/v1/members` | 註冊。須 `agreed: true`。`data` 含 `token`、`member`，並按 `ref` 綁上級 |
| POST | `/api/v1/member-sessions` | 登錄。郵箱+密碼，或手機+已發到綁定郵箱的驗證碼。須勾選協議 |
| DELETE | `/api/v1/member-sessions/current` | 會員退出 |
| GET | `/api/v1/members/me` | 當前會員 |
| PATCH | `/api/v1/members/me` | 更新當前會員，如 `{ "locale": "zh-HK" \| "en" }` |
| PATCH | `/api/v1/member-passwords` | 驗證碼通過後改密碼，不自動登錄 |
| GET | `/api/v1/tabbar` | 公開。兩個語言的文案都返回，H5 按當前語言取 |
| POST | `/api/v1/admin/sessions` | 管理員登錄 |
| DELETE | `/api/v1/admin/sessions/current` | 管理員退出 |
| GET | `/api/v1/admin/admins/me` | 當前管理員 |
| GET / PUT | `/api/v1/admin/tabbar` | 讀寫四個槽位和底欄背景 |

H5 每次進入帶底欄的頁面都請求 `GET /api/v1/tabbar`。失敗時用本次打開後最近一次成功的配置（`sessionStorage`）；還沒成功過就用內建的四個文案和當前配色，底欄仍可點。

## 5. 後續表（本輪不建）

### M3 商品與文章（已建，見 `apps/api/database/m3_catalog.sql`）

- `categories`（`parent_id`、圖標、排序、狀態）+ `category_i18n`
- `products` + `product_i18n`（名稱、摘要、詳情）
- `product_media`（圖片或視頻、排序）
- `spec_groups` / `spec_options` 及各自 i18n
- `skus`（價、對比價、庫存、圖片）+ `sku_options`
- `service_tags` + i18n，商品多對多勾選（`product_service_tags`）
- `product_badges`：`new` / `editor` / `hot` / `flash`（活動秒殺角標仍可後期自動帶）
- `articles`（穩定代碼如 `terms`、`privacy`，頁腳開關、排序）+ `article_i18n`
- 已售展示：`shop_settings.sold.display_mode` = `exact` \| `fuzzy`
- 首頁輪播/展示區表（`home_banners` 等）本輪仍用 H5 靜態配置，後續再接

### M4 交易

`addresses`、`carts`、`cart_items`、`orders`、`order_items`、`payments`（模擬支付）。地址限制香港。

### M5 履約

`shipments`、`shipment_nodes`（後台錄入，不接快遞公司）、`aftersales`。

### M6 資產

`member_levels`、`coupons`、`coupon_grants`、`point_logs`、`balance_logs`。會員表到那時再加等級、積分、餘額，不在本輪預先加空列。

### 二期

`seckill_events`、`seckill_skus`、`commissions`、`withdrawals`。一期不建，H5 秒殺和分銷繼續 Mock。
