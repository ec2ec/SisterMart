## 目标

### P1 售後佣金沖回

1. 售後退款完成時，按售後數量對應訂單明細的佣金比例沖回  
2. `pending`：累計沖滿則 `void`；未滿則 settle 時只入帳淨額  
3. `settled`：扣減 `commission_available`（不低於 0），累計沖滿則 `clawed_back`  
4. 冪等：`commission_clawbacks.aftersale_id` 唯一  

### P2 分享瀏覽積分

1. 表 `share_views`；`(owner_id, product_code, viewer_ip)` 唯一  
2. 分值讀 `shop_settings.points.share_view`（默認 2）；自看 / 未知 ref 不計  
3. API 回 `mock: false`；H5 契約不變

1. 下級完成單 → 上級 settled + available；售後退款後 available 下降且明細 `clawed_back`（或淨額）
