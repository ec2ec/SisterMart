## 一期策略

| 项 | 决策 |
| --- | --- |
| 主目标 | 闭环购物全流程（浏览→登录→下单→模拟支付→履约售后） |
| 登录 | 邮箱+密码为主；WhatsApp **接口占位、不实发** |
| 支付 | **模拟支付成功**；三真渠道二期 |
| 会员等级 2.7 | 一期后端必做 |
| 底栏配置 2.8 | 一期后端必做（每次进页拉取） |
| 新用户配置 | 一期后端必做：注册开关；注册礼（自动发券多选 / 赠余额 / 赠积分）默认全关，新用户默认无资产 |
| 券 / 积分抵扣 / 余额 / 售后 / 自动收货 / 发货物流 | 一期都要（后端真做） |
| 秒杀 / 分销 | 一期 **前端 Mock**；二期后端 |
| 积分商城 / 签到 / 分享浏览积分 | 前端可先交互；后端按里程碑表（详见范围对照） |
| 部署 | 自建 VPS（后期提供） |
| 参考素材 | 后期提供 |
