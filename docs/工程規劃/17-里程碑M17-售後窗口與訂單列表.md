## 范围（三块，已完成）

### A. 售後有效期 + WhatsApp（過期態）

1. 後台可配窗口天數：`shop_settings.aftersale.window_days`（默認 **30**）  
2. 客服號：`shop_settings.cs.whatsapp`（E.164，供 `wa.me`）  
3. **錨點**：訂單 `completed_at` 起算；未完成（待發貨/待收貨）不受窗口限制，仍可按狀態申請  
4. 已完成且 `now > completed_at + N 天`：  
   - 文案：「抱歉，已超過售後有效期，暫時無法申請售後」  
   - 按鈕：「直接聯繫我們 WhatsApp」→ 打開 `https://wa.me/{digits}?text=...`（預填訂單號）  
5. 後端 `apply` 同步拒絕（`AFTERSALE_EXPIRED`），防繞過前端  

### B. 正常售後申請頁整改 + 證據入庫

1. 退款去向「退回餘額 / 原路退回」：選中項前方 **✅**  
2. 原因說明：單一多行輸入，placeholder「請詳細描述你遇到的問題」  
3. 上傳圖片證據：最多 **3** 張；單張 ≤ **1MB**；jpeg/png/webp  
4. 新上傳接口 → 存 `public/storage/aftersale/...` → URL 寫入已有 `aftersales.evidence_json`  
5. 售後詳情 / 後台審核可查看證據圖  

### C. 我的訂單列表 — 行首商品縮略圖

1. `GET /orders` 摘要含 `cover`、`title`、`item_count`；H5 `OrdersView` 行首展示縮略圖  
2. 無圖時占位；點擊進訂單詳情
