# SisterMart 數據庫結構說明

> 庫名：`sistermart`（遠程測試庫同構，庫名可能為主機分配名）  
> 字符集：`utf8mb4` / `utf8mb4_unicode_ci`  
> 來源：現行 MySQL + `apps/api/database/m2`–`m6`、`m11_seckill.sql`、`m12_points_mall.sql` 建表腳本  
> 表數量：**42**

## 總覽

| 分組 | 表 |
| --- | --- |
| 認證與權限 / M2 | `admin_roles`、`admins`、`admin_tokens`、`members`、`member_tokens`、`verify_codes`、`shop_settings`、`tabbar_items` |
| 目錄與內容 / M3 | `categories`、`category_i18n`、`products`、`product_i18n`、`product_media`、`product_badges`、`spec_groups`、`spec_group_i18n`、`spec_options`、`spec_option_i18n`、`skus`、`sku_options`、`service_tags`、`service_tag_i18n`、`product_service_tags`、`articles`、`article_i18n` |
| 交易 / M4 | `addresses`、`carts`、`cart_items`、`orders`、`order_items`、`payments`、`coupons`、`coupon_grants` |
| 履約與售後 / M5 | `shipments`、`shipment_nodes`、`aftersales` |
| 資產與等級 / M6 | `member_levels`、`point_logs`、`balance_logs` |
| 秒殺 / M11 | `seckill_sessions`、`seckill_items` |
| 積分商城 / M12 | `points_mall_items` |

## ER 關係（簡圖）

```
members ──< orders ──< order_items
   │           ├── payments
   │           ├── shipments ──< shipment_nodes
   │           └── aftersales
   ├── addresses / carts ──< cart_items
   ├── coupon_grants >── coupons
   ├── point_logs / balance_logs
   └── member_levels
products ──< skus ──< sku_options >── spec_options >── spec_groups
   ├── product_i18n / product_media / product_badges
   └── categories (樹)
admins >── admin_roles ; admin_tokens
```
