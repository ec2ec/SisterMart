# 接口约定（M0 占位）

状态：M0 仅冻结原则；详细 OpenAPI / 路由表自 M1–M3 起补全。

## 原则

- 后端唯一入口：`apps/api`（ThinkPHP 8.1）
- H5 / Admin 均消费同一 API（权限与角色区分）
- 认证：H5 與後台各自的 Bearer 令牌（M2 起，見 `../工程規劃/06-數據表與後台信息架構.md`）
- 支付：模拟支付接口（M5）；禁止一期接入真实渠道
- 秒杀 / 分销：一期提供 Mock 契约（M6），响应形状稳定以便前端联调
