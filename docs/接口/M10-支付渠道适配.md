# M10 — 支付渠道适配接口

## 模式

| 环境变量 | 含义 |
| --- | --- |
| `PAYMENT_MODE=mock`（默认） | 全部渠道走 `MockPaymentChannel`；H5 继续 `POST /payments/:id/mock-confirm` |
| `PAYMENT_MODE=live` | 未配齐密钥 → `PAYMENT_NOT_CONFIGURED`；已启用但未实作 → `PAYMENT_CHANNEL_PENDING`（M11） |

## 创建支付（会员鉴权，行为增强）

`POST /api/v1/orders/:id/payments`  
Body: `{ "channel": "fps" | "alipay_hk" | "wechat_hk" }`

成功 `data` 新增：

| 字段 | 说明 |
| --- | --- |
| `mode` | `mock` / `live` |
| `next` | Mock 时含 `action=mock_confirm` 与确认路径 |

## 模拟确认（兼容）

`POST /api/v1/payments/:id/mock-confirm` — 行为与 M5 相同（幂等）。

## 异步回调（公开）

`POST /api/v1/payment-callbacks/:channel`  
`:channel` ∈ `fps` | `alipay_hk` | `wechat_hk`

- Mock 模式：body 需含 `payment_id`，校验通过后落账  
- Live + 未配置：`503` / `PAYMENT_NOT_CONFIGURED`，**不改订单**  
- Live + Stub：`501` / `PAYMENT_CHANNEL_PENDING`

## 真渠道所需配置（M11 接通前先备齐）

| 渠道 | 环境变量 |
| --- | --- |
| FPS | `PAYMENT_FPS_ENABLED` `PAYMENT_FPS_MERCHANT_ID` `PAYMENT_FPS_SECRET` |
| AlipayHK | `PAYMENT_ALIPAY_HK_ENABLED` `PAYMENT_ALIPAY_HK_APP_ID` `PAYMENT_ALIPAY_HK_PRIVATE_KEY` `PAYMENT_ALIPAY_HK_PUBLIC_KEY` |
| WeChat HK | `PAYMENT_WECHAT_HK_ENABLED` `PAYMENT_WECHAT_HK_MCH_ID` `PAYMENT_WECHAT_HK_API_KEY` `PAYMENT_WECHAT_HK_APP_ID` |

可选：`PAYMENT_CALLBACK_BASE=https://sistermart.vip/api/index.php`
