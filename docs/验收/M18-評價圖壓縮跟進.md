# M18 跟進 — 通用圖片壓縮 + 評價圖上傳預覽

| 项 | 内容 |
| --- | --- |
| 状态 | **本地验收通过** |
| 分支 | `cursor/m18-review-image-process-fc0f` |
| 脚本 | `scripts/m18-accept.mjs`（含評價圖 + 後台通用上傳） |

## 通用能力

`ImageProcess::compress($opts)` + `ImageUploadService`（preset / 顯式參數）：

| preset | 最長邊 | 目標體積 | 用途 |
| --- | --- | --- | --- |
| `review` / `aftersale` | 1200 | ≤500KB | 會員評價 / 售後 |
| `product` / `admin` | 1600 | ≤700KB | 後台商品 / 通用 |
| `banner` | 1920 | ≤800KB | 首頁橫幅 |

- 一律**保持比例**（僅縮最長邊），輸出 **JPG**
- 可覆蓋：`max_edge` / `max_bytes` / `quality` / `min_quality`
- 會員上傳固定 preset（不可繞過）；後台 `POST /api/v1/admin/uploads/image` 可選 preset 與參數

## 評價圖（會員）

1. 上傳上限 **5MB**  
2. preset=`review`：最長邊 ≤1200，≤500KB JPG  
3. 商品詳情縮略圖 + `showImagePreview` 全屏  

## 後台

- `POST /api/v1/admin/uploads/image` + Admin `uploadImage()` helper  
- 商品編輯頁可直接上傳（`preset=product`）  

## VPS

確保 PHP-FPM `upload_max_filesize` ≥ 8M（或部署 `public/.user.ini`），並可寫 `public/storage/{review,aftersale,product,banner,admin}`。
