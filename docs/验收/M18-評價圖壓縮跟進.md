## 范围

1. 評價上傳上限 **5MB**（售後證據仍 1MB）  
2. 服務端 GD：等比縮放最長邊 ≤ **1200**，輸出 **JPG**，體積 ≤ **500KB**  
3. 商品詳情評價圖為小縮略圖，點擊 `showImagePreview` 全屏預覽  
4. PHP：`public/.user.ini` + 本地 `php-dev.ini`（upload 8M / post 12M）  

## VPS

確保 PHP-FPM `upload_max_filesize` ≥ 8M（或部署 `public/.user.ini`），並可寫 `public/storage/review`。
