# M8 — 支付 / 退款 / 入账幂等说明

## 支付确认（mock-confirm）

- 入口：`POST /api/v1/payments/{id}/mock-confirm`
- 行为：事务内 `SELECT … FOR UPDATE` 锁定 payment + order。
- 若 `payments.status = paid`：直接返回订单详情，**不重复**改订单状态。
- 若订单已非 `pending_payment`：返回 `INVALID_STATUS`。
- 验证：同一 `payment_id` 连续确认两次，第二次仍 `code=0` 且订单仍为 `pending_shipment`，支付单仍一条 `paid`。

## 确认收货 / 自动收货

- 入口：`POST /api/v1/orders/{id}/confirm-receipt`、`POST /api/v1/jobs/auto-receive-orders`
- 已 `completed`：直接返回详情（幂等），**不重复**发积分、不重复累加 `total_spent`。
- 事务内按 `pending_receipt` 加锁；`points_awarded` 二次发放保护仍保留。
- 验证：完成后再次确认收货 → 成功返回且积分流水仅一条 `order_earn`。

## 售后退款

- `executeRefund`：若售后单已 `completed`，直接返回详情。
- 余额入账写 `balance_logs`；整单退完退积分写 `point_logs`。
- 库存按售后 qty 回补；重复执行不会再进事务扣款路径。

## 关单释放资产

- `close-expired-orders`：仅处理 `pending_payment` 且过期订单；释放库存/券/积分/余额并写流水。
- 已取消订单再次跑任务无操作。

## 签到 / 分享浏览（M7 Mock）

- 签到：同月同日不可重复（日历状态）。
- 分享浏览：`ref + product + IP` 去重键存在则 `credited=false`。
