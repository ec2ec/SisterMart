## 公网已知约定

1. **路由**：H5/Admin 使用 **hash**（`/#/...`），因共享主机 nginx 未配 `try_files`。面板加上 `releases/vps-spa/nginx-伪静态.conf` 后可改回 History。
2. **API 入口**：`https://sistermart.vip/api/index.php/api/v1/...`
3. **FTP**：Cloud Agent 出口对 Pure-FTPd STOR 不稳定，易写 0 字节文件；发布请用本机 FTP。
4. **Mock**：秒杀、分销、支付渠道均为模拟，不得当作真实资金/库存能力。
