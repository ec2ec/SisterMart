# M9 — 测试环境部署与环境变量

## 目标

将 SisterMart（API + H5 + Admin）发布到测试机 / 自建 VPS，给出访问地址与演示账号。

> 若尚未提供 VPS：可先用本仓库脚本在本机完成 **生产构建验收入口**；拿到主机后执行 `scripts/deploy/install.sh`。

## 推荐拓扑

```text
Internet
   │
 Nginx（443/80）
   ├─ /            → apps/h5/dist      （H5）
   ├─ /admin/      → apps/admin/dist   （后台，可选子路径或独立子域）
   └─ /api/        → PHP-FPM ThinkPHP  （apps/api/public）
         └─ MySQL 127.0.0.1:3306
```

也可三端分域名：`shop.example.com` / `admin.example.com` / `api.example.com`。

## 环境变量清单

### API（`apps/api/.env`）

| 键 | 示例 | 说明 |
| --- | --- | --- |
| `APP_DEBUG` | `false` | 测试环境建议 false |
| `DB_TYPE` | `mysql` | |
| `DB_HOST` | `127.0.0.1` | |
| `DB_NAME` | `sistermart` | |
| `DB_USER` | `sistermart` | |
| `DB_PASS` | `***` | 生产请换强密码 |
| `DB_PORT` | `3306` | |
| `DB_CHARSET` | `utf8mb4` | |
| `DEFAULT_LANG` | `zh-cn` | ThinkPHP 内部语言 |

### H5 构建（`apps/h5/.env.production` 或 CI 注入）

| 键 | 示例 | 说明 |
| --- | --- | --- |
| `VITE_API_BASE` | `https://api.example.com` | 浏览器可访问的 API 根 |
| `VITE_APP_LOCALE` | `zh-HK` | 默认语言 |

### Admin 构建

| 键 | 示例 |
| --- | --- |
| `VITE_API_BASE` | `https://api.example.com` |
| `VITE_APP_LOCALE` | `zh-HK` |

## 一键脚本

| 脚本 | 用途 |
| --- | --- |
| `scripts/deploy/build-frontends.sh` | 生产构建 H5 + Admin |
| `scripts/deploy/install.sh` | 目标机：依赖、库表、构建、Nginx 示例 |
| `scripts/deploy/backup.sh` | MySQL + 代码快照 |
| `scripts/deploy/rollback.sh` | 从最近备份回滚 |
| `scripts/m9-accept.mjs` | 构建产物 + 演示账号 + 模拟支付冒烟 |

## 备份与回滚

1. **备份**：`bash scripts/deploy/backup.sh` → `backups/YYYYMMDD-HHMMSS/`（`db.sql.gz` + `apps.tgz`）
2. **回滚**：`bash scripts/deploy/rollback.sh backups/YYYYMMDD-HHMMSS`
3. 建议日备 + 发布前强制备一份

## 安全注意

- 测试环境关闭 `APP_DEBUG`
- MySQL 不对外网暴露
- 演示密码仅用于测试，上线前更换
