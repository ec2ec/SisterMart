本《退款政策》說明 SisterMart（姐妹商店）何時及如何退款，並與《退貨政策》《運送政策》《用戶協議》一併適用。退款並非自動權利：須符合本政策及《退貨政策》，並經我們審核／驗貨確認。為保障店家合法權益與防範濫用，我們保留核實交易、調整退款構成、分期或延後處理，以及在合理情況下拒絕或僅部分退款之操作空間（法律強制規定除外）。

1. 可退款情形

  • 按《退貨政策》完成退貨，且收貨檢驗合格後
  • 付款成功後，因我們原因長期未能出貨，且你選擇取消，經我們確認可取消之訂單
  • 經核實之重複扣款、系統計價錯誤、明顯多收運費或其他我方責任之金額錯誤
  • 錯發／漏發且雙方同意以退款代替補發或換貨
  • 其他我們書面同意退款之情形

2. 不退款或僅部分退款之情形

  • 不符合《退貨政策》或驗貨不合格
  • 已使用之優惠權益、不可撤回之第三方費用、或商品貶值／缺件部分
  • 因顧客提供錯誤地址、拒收、不取件導致之額外物流成本（可自退款中扣除）
  • 贈品、包裝耗材、發票手續等已發生且無法退回之成本（按個案說明）
  • 涉嫌欺詐、調包、惡意拒付或濫用售後

3. 退款構成與計算

  1. 商品款：原則按該件實付金額計算（已扣除該件分攤之優惠後）。
  2. 訂單優惠／滿減／券：退款後若剩餘商品不再滿足活動門檻，我們有權追回相應優惠差額（自退款中扣減或要求補差）。
  3. 積分：下單抵扣之積分，可按規則返還；因本筆訂單已發放之積分，我們有權扣回。積分商城兌換訂單之退款規則可另行限制。
  4. 運費：
    • 質量問題／錯發：原訂單運費與經同意之寄回運費，可按合理範圍退還或報銷
    • 非質量問題：原訂單運費通常不退；寄回與補發運費由顧客承擔
    • 部分退貨後剩餘商品未達免運門檻：可自退款中補收應付運費
  5. 手續／檢測／補貨費：對個人原因退貨或狀態瑕疵但仍協商處理之個案，我們可扣除合理費用後再退餘額。

4. 退款方式

  • 原則退回原支付途徑（信用卡／支付平台／其他當次付款渠道）。
  • 若原途徑無法退回或已失效，我們可在通知你後改以其他合理方式處理（例如商店餘額、優惠券折讓或雙方同意之轉帳安排）。
  • 我們不保證以現金或非原途徑即時退款；具體以可執行之支付渠道規則為準。

5. 處理與到帳時間

  • 起算點：以我們完成驗貨（如適用）並在系統確認「同意退款」之日起算，而非你提交申請或寄出商品之日。
  • 我方處理：確認後一般於 3–15 個工作天內提交退款指令（遇對帳、風控、節假日或支付機構審核可能延長）。
  • 到帳：支付機構／銀行入帳通常另需數個工作天，實際以對方為準；我們無法控制第三方到帳速度。
  • 同一訂單多次售後、爭議未決或需補證時，我們可暫停退款直至事項澄清。

6. 取消訂單與出貨後

  • 未出貨：可申請取消；是否成功視倉庫作業進度。已開始揀貨／交運者，可能無法取消，改按退貨流程。
  • 已出貨：不支持僅以「不想要」為由直接線上全額退款；須按《退貨政策》退回並驗貨。
  • 你已申請支付機構爭議／拒付時，我們可中止雙軌處理，優先以爭議結果及證據為準，並保留提供物流與溝通紀錄之權利。

7. 部分退款與換貨差價

多件訂單可只退符合條件之部分。換貨涉及差價時，多退少補；少補未完成前，我們可暫不發出替換商品。部分退款之運費與優惠重算依第 3 節。

8. 發票與記錄

退款完成後，交易記錄、積分與優惠狀態以系統為準。如需調整發票／收據記載，請在退款完成後聯絡客服，我們於合理範圍協助。

9. 酌情權與防濫用

在適用法律允許範圍內，SisterMart 可就爭議個案作出合理商業判斷（包括部分退款、延期、折讓替代現金、或拒絕）。對異常高頻退貨、拒付或虛假陳述，我們可限制購買／售後權限，並保留追討已退款項及相關損失之權利。
