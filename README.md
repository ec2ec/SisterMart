# SisterMart

Monorepo：用户端 H5、管理后台、ThinkPHP API。

仓库：`https://github.com/ec2ec/SisterMart.git`

## 目录

```text
apps/api      # ThinkPHP 8.1 + MySQL
apps/h5       # Vue3 + Vant4
apps/admin    # Vue3 + NaiveUI
docs/         # 需求 / 工程 / 接口 / 验收
refs/         # 外部参考
scripts/      # 工程脚本
```

## 冻结决策（摘要）

| 项 | 决策 |
| --- | --- |
| 后端 | ThinkPHP 8.1.x + MySQL |
| H5 | Vue 3 SPA + Vant 4 |
| Admin | Vue 3 + Naive UI |
| 登录 | 邮箱为主；WhatsApp 接口占位、不实发 |
| 支付 | 模拟支付（真渠道二期） |
| 一期后端 | 2.7 会员等级 / 2.8 底栏配置；券·积分·余额·售后·发货等主链 |
| 秒杀 / 分销 | 一期前端 Mock；二期后端 |
| 语言 | `zh-HK` / `en` |
| 里程碑 | M0–M9（详细版为准） |
